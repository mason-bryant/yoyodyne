# v0.5.0

Covering v0.4.0 to v0.5.0. The release date is the tag's.

This release is about the harness keeping itself running. A provider that is logged out or unreachable is now a named wait rather than a three-day silence; the intake brake summons the development manager and releases itself instead of holding for a person; a review sees the whole change it judges; and the caps count only rounds that found something wrong. Alongside those, the dashboard ships whole, the product manager's conversation reaches Slack, and the product's services are declared in one configuration section ahead of starting them together.
